# Documentação

## Projeto Spring Boot 

Projeto pessoal para melhorar o aprendizado com 
* Spring Web
* Spring Data JPA
* Spring Security
* Lombok
* Validation
* MySQL Drive
* JWT token

O projeto usa uma arquitetura em microserviços onde temos o package Service
onde faz a manipulação de dados como adicionar, atualizar, remove.

No package de Database no Repositorio fiz Query SQL mesmo sabendo que existem comandos prontos como o save
mas preferir criar os comandos para ganhar aprendizado.

No Security usei comandos via Youtube.
